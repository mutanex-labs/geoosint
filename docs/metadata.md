# Metadata First

Оригинал → размер/структура/формат → EXIF/XMP → нормализация GPS → проверка диапазонов
→ Evidence с hash оригинала → preflight. Облачных моделей и географической сети в
этом конвейере нет. Отсутствие GPS направляет к обычному расследованию и Scope.

Подтверждённые тестами форматы: JPEG, PNG, WebP, TIFF. Библиотека Pillow 12.3.0,
XML — defusedxml 0.7.1; версии зафиксированы в uv.lock. HEIC/HEIF пока отклоняются:
дополнительный адаптер без реальных образцов не объявляется работающим.
Формат определяет Image.open по содержимому; расширение не используется как истина.
Метаданные читаются лениво, без Image.load и декодирования всех пикселей.

## Что возвращается

case_id/artifact_id, detected_format, original_sha256, metadata_status,
gps_present/gps_valid, latitude/longitude, altitude_m, gps_timestamp,
capture_timestamp, timestamp_timezone_status, gps_accuracy_m, parser_name/version,
warnings, conflicts, evidence_id, sources и provenance каждого нормализованного поля.
Отсутствующие значения null. Дополнительные EXIF-поля выводятся по allowlist;
серийные номера и MakerNote не публикуются. Оригинал в MCP-ответ не включается.

DMS с рациональными дробями и N/S/E/W проверяются формально; нулевые знаменатели,
NaN, выход за диапазон и неполные компоненты не превращаются в координаты.
AltitudeRef=1 даёт отрицательную высоту. GPSHPositioningError читается как метры,
GPSDOP остаётся безразмерным отдельным значением и не подменяет accuracy.
GPSImgDirection различает истинный и магнитный север.

GPSDateStamp + GPSTimeStamp — UTC; DateTimeOriginal/CreateDate без OffsetTime не
считаются UTC. Часовой пояс по координатам или настройкам сервера не угадывается.
Рефракция, DEM и направление камеры по EXIF отдельно не доказываются.

XMP имеет отдельное происхождение. Поддержаны GPSLatitude/GPSLongitude в форме
градусы,минуты[N/S/E/W] либо градусы,минуты,секунды[N/S/E/W]. Другие варианты
не угадываются. Конфликт валидных EXIF/XMP сохраняет оба источника и возвращает
CONFLICTING_GPS с итоговыми координатами null.

## GPS не равен истине сцены

METADATA_PRESENT — поле найдено; METADATA_VALID — разобрано корректно;
LOCATION_VERIFIED требует независимого подтверждения связи со сценой.
Результат только из файла — EMBEDDED_GPS/METADATA_LOCATION. Он может быть назначен
приложением, устареть, относиться к другому месту или быть подделан.

Если GPS указывает на океан, а наблюдения — на пустыню, EXIF не становится STRICT,
не удаляет альтернативы и не завершает дело. Наблюдение с conflicts_with_artifact_ids
помечает соответствующие Evidence как NEEDS_REVIEW, дело — REVIEW_REQUIRED.
Автоматический land/water-анализ этой
версией не выполняется. Агент должен сохранить противоречие и отдельно проверить
обе гипотезы. Сервер не утверждает, что видел сцену, только потому что получил байты.

## Передача оригинала

Файл, показанный в ChatGPT, не считается автоматически доступным MCP. Интерфейс
может передать преобразованное изображение без исходных метаданных. Не обещается
прямая передача вложения через MCP; такой интеграционный тест не проводился.

Локально: `geoosint metadata inspect original.jpg --json --no-store` — без сервера,
создания дела и записи оригинала. `--case-id CASE_ID` сохраняет в существующее дело
через тот же сервис. `--no-store` всегда запрещает сохранение.

Удалённо: сначала OAuth-доступ и geo_case_create, затем отдельная защищённая загрузка
оригинального файла. Например, из терминала пользователя:

```bash
curl --fail-with-body -X POST "$BASE_URL/cases/$CASE_ID/artifacts" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "If-Match: $REVISION" -H "Idempotency-Key: $UPLOAD_KEY" \
  -H "Content-Type: application/octet-stream" --data-binary @original.jpg
```

Секреты задаются локально пользователем, не помещаются в репозиторий, чат или логи.
Upload сразу возвращает preflight с GPS и evidence_id. Для повторной проверки в
geo_case_preflight передаются только case_id, artifact_id, новая revision и ключ.
Запрос извлечь метаданные не разрешает внешнее географическое исследование.

## Ограничения

25 MiB исходного файла, до 10 оригиналов на дело; конфигурируются GEO_MAX_UPLOAD_BYTES
и GEO_MAX_ARTIFACTS_PER_CASE. Метаданные до 1 MiB, XML depth до 20, до 2048 XML-элементов,
размер изображения до 40 млн пикселей. Серверный subprocess прерывается через 5 секунд.
Это ограничение времени, а не отдельная OS sandbox для нативного кода Pillow.

Удаление geo_artifact_delete очищает оригинал, содержимое Evidence и приватные
idempotency snapshots; отчёт помечает невозможность повторной проверки. Удаление дела
удаляет все его файлы. Backup и снимки диска истекают по отдельной политике оператора.

Быстрый metadata-only результат не подтверждает подлинность камеры, отсутствие
редактирования, истинность GPS или визуальное совпадение с панорамой.
