# Отказы каналов и остановка

Отказ Overpass → сохраните diagnostics, бюджет и неуспешное покрытие; используйте
доступные веб-страницы, местные источники, фото или карты клиента. Не переключайте
экземпляры для обхода 429/Retry-After. Выбор разрешённого экземпляра — настройка оператора.

Нет GPS → переходите к наблюдениям и Search Scope. Нет текста → используйте отличимую
геометрию/инфраструктуру/рельеф; не создавайте OCR-результат. Нет объекта в OSM → проверьте
другой доступный источник; неполная карта не доказывает отсутствие места.

Нет веб-поиска → используйте известные пользовательские URL и доступное чтение страниц.
Нет чтения страниц → выдача остаётся SEARCH_RESULT, повышать достоверность нельзя.
Нет просмотра картинок → пропустите визуальную проверку и явно отразите её отсутствие.
Недоступен конкретный сайт → зафиксируйте URL/ошибку без содержимого секретов и рассмотрите
независимый источник. Не обходите CAPTCHA, paywall и ограничения доступа.

Перед UNRESOLVED перечислите оставшиеся способы проверки и почему они недоступны,
слишком дороги либо не способны различить кандидатов. Общие признаки и ограниченный
бюджет — обоснованная причина остановиться; сбой единственного API при доступном полезном
веб-поиске — нет. Пользовательский STOP прекращает работу независимо от гипотез.
