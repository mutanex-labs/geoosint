# Верификация

Разделяйте наблюдение модели, пользовательскую догадку, корректное вычисление,
внешний факт и подтверждённую локализацию. Прикрепляйте реальные операции, а не
самостоятельно заполненный PASS. Общие зелёная растительность и двухполосная дорога
не равны уникальному пространственному совпадению.

Все производные одной вывески должны иметь общий dependency_group. Источники,
повторяющие OSM, не независимы. Сохраняйте серьёзную альтернативу и противоречия.
Не создавайте статистические проценты из внутреннего рейтинга.

METADATA_VALID проверяет только формальный GPS. LOCATION_VERIFIED требует независимой
связи со сценой; сервер такого верификатора пока не предоставляет. Итог UNRESOLVED
допустим и предпочтителен ложной точности. radius_m=null без измерительных оснований.

| Класс | Что действительно получено |
|---|---|
| SEARCH_RESULT | Выдача/сниппет, источник ещё не проверен |
| PAGE_CONTENT | Прочитанная страница, её утверждения требуют оценки |
| VISUAL_REFERENCE | Фактически просмотренное изображение/панорама |
| MODEL_COMPARISON | Клиентская интерпретация двух изображений |
| GEOMETRY_CHECK | Детерминированное вычисление по указанным входам |
| GEO_SOURCE | Объект карты с ID, датой, геометрией и ограничениями |
| VERIFIED_RELATION | Сервер проверил пространственное отношение сохранённых объектов |

Первые клиентские классы сохраняются research в наблюдении и остаются UNVERIFIED.
GEOMETRY_CHECK/VERIFIED_RELATION создаются серверными операциями; их нельзя объявить
вручную в research. Вызов geo_evidence_add связывает реальные операции и наблюдения.
У пространственной проверки эффект SUPPORTS/CONTRADICTS не может противоречить matches.

HYPOTHESIS допускает только предположение. PRELIMINARY требует источника кандидата.
FACT_SUPPORTED требует сохранённых поддерживающих пространственных проверок и отсутствия
противоречащих; это условное соответствие геоданных наблюдениям, не независимое зрение.
Для предварительного отчёта явно передайте assessment, candidate_id и уровень кандидата.
Ни один из этих статусов не ставит RESOLVED/LOCATION_VERIFIED. При отсутствии достаточной
географической привязки — UNRESOLVED с сохранёнными поисковыми направлениями.
